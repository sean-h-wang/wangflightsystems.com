Technical Report: Aerodynamic Limitations of the Diverging Ram Inlet and a New Engine Concept

This report evaluates the physical trade-offs of the diverging ram inlet concept using 2D inviscid CFD modeling. Localized Prandtl-Meyer expansion fans and the total duct length required for shock reflections introduce practical integration challenges. To address these constraints, we present an updated propulsion architecture incorporating an external compression inlet, compressor, rotating detonation engine, and a custom swirl recovery waterwheel device.
